# ☕ JavaQuest

> Minha jornada para aprender Java e Programação Orientada a Objetos através da criação de um RPG.

## 📖 Sobre o projeto

O **JavaQuest** é um projeto pessoal criado com o objetivo de aprender e praticar **Java** e os principais conceitos de **Programação Orientada a Objetos (POO)** através do desenvolvimento incremental de um RPG de fantasia.

A ideia é começar com uma aplicação simples e evoluí-la conforme novos conceitos são aprendidos, transformando o projeto em um laboratório prático para experimentar Java, boas práticas de programação e, futuramente, desenvolvimento de aplicações web.

O projeto não tem como objetivo ser um RPG comercial ou um jogo completo. Seu principal propósito é **aprender Java na prática**.

---

## 🎯 Objetivos

- Aprender Java através de um projeto prático
- Compreender os fundamentos da Programação Orientada a Objetos
- Praticar boas práticas de desenvolvimento
- Aprender a estruturar e organizar um projeto Java
- Experimentar diferentes recursos da linguagem
- Evoluir gradualmente para conceitos de desenvolvimento backend

## ⚔️ O projeto

O JavaQuest será construído ao redor de um pequeno universo de fantasia, inicialmente explorado através do terminal.

Entre as funcionalidades planejadas estão:

- 🧙 Personagens
- ⚔️ Classes e habilidades
- 👹 Criaturas e inimigos
- 🎒 Inventário
- 🗡️ Equipamentos
- 📜 Missões
- 🏰 Locais e cidades
- 💰 Sistema de itens e comércio
- ⚔️ Sistema de combate
- 💾 Salvamento de progresso

Essas funcionalidades não serão implementadas de uma só vez. Cada uma será utilizada como oportunidade para aplicar novos conceitos aprendidos em Java.
